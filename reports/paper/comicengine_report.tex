\begin{abstract}
We present \textbf{ComicEngine}, a modular, code-first system for generating educational history comics with recurring characters, tracked API spend, and human-in-the-loop curation.
Built for \emph{onceuponatime} (bedtime narratives that explain real events to children), the system separates \emph{coding/LLM} traffic (optionally via OmniRoute at \texttt{localhost:20128}) from \emph{image generation} (direct commercial APIs: fal FLUX, Google Gemini image).
This living report records what each phase actually ran, what worked, quantitative ledger totals from SQLite (\texttt{data/usage.db}), style bake-off judge scores, and interim character-consistency findings.
\textbf{As of this snapshot:} 52 tracked API calls, \textbf{$\approx\$0.532$} total estimated spend (Phase~3 alone $\approx\$0.387$). Style human judge still pending; interim active style \texttt{korean\_manhwa}. Phase~3 consistency bake-off finished with \textbf{0 failures} (22/22 images): winner method \texttt{gemini\_ref}; reserve \texttt{flux\_kontext} for hard Abhijeet retries; \texttt{text\_only\_fal} for cheap drafts.
\end{abstract}

\section{Introduction}
Production AI comics need character/style consistency, predictable cost, commercially licensed image paths, and an auditable spend ledger.
ComicEngine addresses these with phasal CLIs, Pydantic episode JSON, style presets, and a FastAPI dashboard (Tasks, Stories, Analytics, Images, and this Report PDF at \texttt{/report}).

\paragraph{Test story.}
End-to-end stress test: dramatized bedtime episode about the Cockroach Janta Party (CJP) / fair-exam student protests (characters including Abhijeet Dipke, Saurav Das, public figures portrayed respectfully for pipeline testing only).

\paragraph{Living-document policy.}
After every phase gate we (1)~append empirical results to this \texttt{.tex}, (2)~rebuild the PDF, and (3)~include the report update in the same phase merge to \texttt{master}.

\section{Routing and Licensing Constraints}
\begin{itemize}[leftmargin=*,itemsep=1pt]
  \item \textbf{Text / coding LLMs:} OmniRoute when \texttt{USE\_OMNIROUTE=1} + \texttt{OMNIROUTE\_API\_KEY}.
  \item \textbf{All images:} direct \texttt{.env} keys only (\texttt{FAL\_API\_KEY}/\texttt{FAL\_KEY}, \texttt{GOOGLE\_API\_KEY}) — never OmniRoute.
  \item Local FLUX~\texttt{[dev]} / Kontext~\texttt{[dev]} remain R\&D-only under BFL non-commercial terms; production-like finals use commercial fal/Gemini APIs.
\end{itemize}

\section{Architecture (stable through Phase~3)}
\texttt{src/comicengine/}: config, pricing, tracked clients, styles, analytics, stories, gallery, tasks.
\texttt{scripts/}: phase CLIs. \texttt{dashboard/}: FastAPI + static UI.
\texttt{data/usage.db}: per-call ledger. \texttt{data/style\_lock.json}: bake-off + human-judge flags.
\texttt{outputs/}: episode JSON, images, reports.

\paragraph{Evaluation stack.}
Pillow heuristics (existence, min dims, mean brightness/variance anti-blank) write \texttt{image\_quality} into call metadata.
Analytics derives model recommendations (\texttt{data/model\_recommendations.json}) — advisory only; scripts do not auto-switch.

\paragraph{Decision (ship).}

\section{What We Explicitly Learned}
\begin{enumerate}[leftmargin=*,itemsep=2pt]
  \item OmniRoute is excellent for LLM scripting/judging; keeping images off OmniRoute avoided opaque image billing and matched commercial-key policy.
  \item fal~\texttt{schnell} makes wide style exploration financially trivial (\textasciitilde\$0.024 for 8 bake-off frames).
  \item Auto style judges trade off immersion vs.\ bedtime safety; human adjudication remains mandatory for product voice.
  \item Pillow ``pass'' is necessary but not sufficient for character consistency; the Phase~3 LLM judge correctly ranked \texttt{gemini\_ref} over cheaper text-only despite identical QA scores.
  \item Gemini new-user model allowlists forced early Phase~0 remapping; document working model IDs in clients, not only marketing names.
\end{enumerate}

\section{Risks and Ethics}
Dramatized civic content for ages $\sim$7--10; respectful depiction of public figures; Commons attribution for place photos; human fact-check before any public publish.
Style and consistency locks must not be decided solely by LLM judges or blank-frame QA.
